# PetLife 
PetLife é uma plataforma web que funciona como uma carteirinha de vacinação digital para pets. O tutor cria uma conta, cadastra seus animais e cada pet recebe um QR code único, que pode ser escaneado por veterinários para registrar as vacinas aplicadas — acabando com o risco de perder a carteirinha física.
Além do controle de vacinação, o projeto conta com:
📍 Pontos de vacinação — página com locais onde os pets podem ser vacinados
🐶 Adoção — espaço para anunciar cães disponíveis para doação
💬 Depoimentos — histórias de tutores e pets que usam a plataforma.
